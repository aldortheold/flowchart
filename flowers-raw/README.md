# Flowchart — Remaining 69 Flower Assets

This package extends the existing approved rose, daisy, and tulip assets into a shared taxonomy of 15 flower types.

## Added flower types

Sunflower, lotus, orchid, hibiscus, poppy, peony, chrysanthemum, dahlia, camellia, anemone, narcissus, and forget-me-not.

## Asset contract

- `512 × 512` SVG canvas with `viewBox="0 0 512 512"`
- Exact `1:1` aspect ratio
- Transparent background
- Directly overhead flower heads only
- No stems or leaves
- No gradients
- No built-in padding: rendered flower bounds touch all four canvas edges
- Dual `href` and `xlink:href` references for broad renderer compatibility

The six existing Botanical and Minimal rose, daisy, and tulip files were not edited or duplicated in this package.
